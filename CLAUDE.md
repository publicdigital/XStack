# Working in the xstack repo

The agent roster and how they work together are in `AGENTS.md`.

## Kestria design system
For any Kestria page, prototype or service, read profiles/kestria/design-system/DESIGN.md first and follow it.
Link profiles/kestria/design-system/tokens.css then profiles/kestria/design-system/kestria.css. Start new pages from profiles/kestria/design-system/example.html.
Never hard-code colours or sizes that have a token; add new tokens to tokens.json and tokens.css first.
